# Local Recorder

## 模块目标

提供一个 macOS 本地录制工作台，让用户能在开始录制前完成设备和分辨率配置，实时预览摄像头画面，录制麦克风声音，并导出 mp4 文件。

## 用户旅程

1. 用户打开应用，进入录制工作台并看到当前摄像头预览。
2. 用户在设备区选择摄像头和麦克风，在分辨率区选择 `720p`、`1080p` 或 `4K`。
3. 用户点击开始录制后，工作台锁定设备选择并持续显示当前摄像头画面。
4. 用户点击停止录制，系统先结束临时写入，再弹出保存面板让用户选择最终导出路径。
5. 导出完成后，系统自动打开导出目录。

## 异常旅程

1. 若系统没有摄像头、麦克风或权限被拒绝，工作台提示用户授权或检查设备。
2. 若 `4K` 不可用，分辨率区显示不可用或降级反馈，用户改用支持的分辨率继续。
3. 若导出失败，系统保留错误反馈并允许用户重新选择保存路径或重试。

## 组件索引

| 组件 | 级别 | 职责 | 文档 |
| --- | --- | --- | --- |
| `RecordingWorkspace` | 完整 | 承载预览、录制控制、状态编排和导出结果反馈 | `RecordingWorkspace.md` |
| `DeviceSelector` | 标准 | 枚举并选择摄像头与麦克风，管理录制前可选和录制中禁用态 | `DeviceSelector.md` |
| `ResolutionProfile` | 标准 | 展示预设分辨率并反馈可用性与降级信息 | `ResolutionProfile.md` |
| `ExportPipeline` | 完整 | 管理停止录制、保存路径确认、编码封装和导出完成回调 | `ExportPipeline.md` |

## 模块关系

- 内部中枢：`RecordingWorkspace`
- 配置输入：`DeviceSelector`、`ResolutionProfile`
- 输出与收尾：`ExportPipeline`

## 已知限制

- 当前实现以 Swift Package 形式交付，可构建运行，但尚未补 Xcode 工程和签名分发流程。
- 录屏模式、自定义背景与复杂后期能力均未纳入当前模块范围。
