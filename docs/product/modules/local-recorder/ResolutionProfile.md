# ResolutionProfile — 分辨率配置

> **模块**：[Local Recorder](index.md) | **级别**：标准 | **最后更新**：2026-05-07

## 关系

| 方向 | 类型 | 目标 | 说明 |
|------|------|------|------|
| → | 触发 | [RecordingWorkspace](RecordingWorkspace.md) | 将选中的分辨率能力与降级信息写回工作台 |
| ← | 依赖 | [RecordingWorkspace](RecordingWorkspace.md) | 工作台读取可用性结果决定是否允许开始录制 |

## 功能

展示 `720p`、`1080p`、`4K` 预设分辨率，并反馈可用性和降级信息。

## 界面结构

```text
[ 720p ] [ 1080p ] [ 4K ]
```

## 交互

| 触发 | 条件 | 行为 | 视觉反馈 |
|------|------|------|---------|
| 打开工作台 | 初始化完成 | 检测各分辨率可用性 | 不可用项显示禁用或提示 |
| 选择分辨率 | 目标分辨率可用 | 更新当前录制分辨率 | 当前项高亮 |
| 选择 `4K` | 设备不支持原生 `4K` | 阻止直接选中或提示降级 | 显示不可用或降级说明 |

## 状态

- **available**：可按该预设录制。
- **unavailable**：设备不支持该预设，禁止直接选择。
- **degraded**：用户意图选择高分辨率，但实际录制需降级。

## 边界情况

- 不同摄像头支持的分辨率集合不同 → 切换摄像头后重算可用性。
- 用户偏好与设备能力冲突 → 自动回退到当前可用的最高档位并明确给出降级反馈。

## Non-Goals（刻意不做）

- 不负责自定义任意宽高比和帧率配置。

## 技术摘要

- 以预设能力矩阵约束工作台配置，减少用户输入复杂度。

## 已知限制

- 降级策略当前固定为向下选择最高可用预设，不提供用户自定义优先级。
